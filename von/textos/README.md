# una imagen que sabe cuándo callarse

Trabajo con imagen fija y en movimiento. No me interesa que todo explique demasiado; me interesa que cada pieza encuentre su temperatura.

La cámara no está para decorar. Está para decidir qué se queda, qué se corta y qué tarda en aparecer.

Una hoja de contacto no oculta los descartes: enseña el rollo completo. Así está armado este archivo, rollo por rollo, sin recortar nada para que cuadre en la página.

Antes que programador, artista. El código solamente es otra cámara.
